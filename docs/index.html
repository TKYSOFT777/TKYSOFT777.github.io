    回路のように、
    アイデアをつなぐ。

    TKYSOFT は、iPhone / iPad 向けのゲームとアプリをつくるインディーデベロッパーです。

    ひとつの点（ノード）から線がのび、別のアイデアとつながって、ひとつの遊びになる。ロゴに込めたのは、そんなものづくりの姿勢です。企画・デザイン・プログラム・運営まで、すべてを自分の手で回しています。

    Ideas are nodes. Code is the trace that connects them.
