PileCount サポート

山積みの段ボールを写真で数え、見えない奥まで推定して報告するアプリです。

よくある質問

数えた数は正確ですか？

見えている箱はマーカーで正確に数えられます。奥の見えない部分は、奥行き（列数）と充填率からの推定値です。精度を上げるには、正面＋側面の2方向以上で撮り、側面写真の箱も打ってください。現場で抜けや欠けに気づいたら、結果画面の「目視で確認して確定する」で補正できます。

どんな積み方に対応していますか？

柱積み・レンガ積み（半個ずらし）・交互積みはグリッドの「揃い／レンガ／交互」で、ピンホイールなど見え方がばらばらな積み方は、奥行きの「1段の個数」で数えられます。

はじめて使うとき、何から始めればいいですか？

ホームの「見本の写真で練習する」で、見本の山を使って、正面を打つ → 側面を打つ → 結果を見る、を手順に沿って試せます。練習は保存されません。

撮影はどう進みますか？

「撮影して数える」で正面を撮ると、続けて左の側面・右の側面・背面を撮るかを1枚ずつ聞きます。とばす・ここで終える・直前の1枚を撮り直す、を選べます。あとから撮り直すときは、カウント画面の右上の「…」か、写真の札の長押しから「撮り直す」を選んでください。

データはどこに保存されますか？

記録は端末の中です。Pro では、あなたの iCloud に同期したり、Google ドライブ・Dropbox・OneDrive・Box のフォルダへ1日1回自動でバックアップしたりできます（あなたのアカウントに直接保存し、私たちのサーバーは通りません）。「AI の改善への協力」がオンのときだけ、学習に使える写真（縮小・顔をぼかしたもの）と箱の位置を送ります。設定でオフにできます。

機種変更のときは？

Pro で iCloud の同期をオンにしていれば、新しい端末で同じ Apple アカウントにサインインし、同期をオンにするだけで戻ります。バックアップのファイル（.pilecountbackup）があれば、新しい端末の 設定 →「バックアップ・同期」→「バックアップから戻す」で戻せます（無料版でも戻せます）。

CSV が文字化けします

設定 →「CSV」→「文字コード」で変えられます。Excel なら「UTF-8（BOM付き）」、古い Excel や業務システムなら「Shift_JIS」、Googleスプレッドシートなら「UTF-8（BOMなし）」がおすすめです。

現場名・担当者を毎回入力するのが面倒です

設定 →「記録の入力」で、よく使う現場名・担当者を登録できます。結果の画面で、入力欄の横のボタンから選べます。

Pro では何ができますか？

履歴の無制限表示、PDFレポート・CSVの書き出し（複数の記録をまとめて1つにも）、報告書への会社ロゴ、iCloud の同期と Google ドライブなどへの自動バックアップ、種別プリセットの無制限、学習・検証用データの書き出しです。数える・推定・確定・報告テキストのコピーは無料版でもずっと使えます。

購入を復元するには？

設定 →「PileCount Pro」→「購入を復元」をタップしてください。

解約するには？

iPhone の「設定」→ あなたの名前 →「サブスクリプション」→「PileCount」から解約できます。アプリの設定 →「プランの変更・解約」からも開けます。
