2. PileCount Pro（自動更新サブスクリプション）

  • 月額プラン・年額プランがあります。価格はアプリ内および App Store に表示されます。
  • 年額プランには、最初の14日間の無料体験があります（はじめて登録する場合のみ）。体験期間の終了の24時間前までに解約しなければ、有料の期間が自動で始まります。
