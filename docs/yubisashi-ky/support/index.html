ゆびさしKY サポート

作業前のKYと指差呼称を、撮る・点検する・声に出すだけで記録するアプリです。

よくある質問

「ヨシ」がうまく聞き取られません

マイクに向かって、はっきり「〇〇ヨシ！」と言ってください。聞き取った文字は画面に表示されます。騒音の大きい現場では、録音中にコントロールセンターの「マイクモード」で「声を分離」を選ぶか、ノイズキャンセリング付きのヘッドセットをお使いください。会社で使う合言葉は、設定 →「音声・聞き取り」で「ヨシ」として追加できます。ボタンでの確認もいつでもできます。

マイクや音声認識が使えません

iPhone の「設定」→「ゆびさしKY」で、マイクと音声認識を許可してください。

点検箇所を登録するには？

設定 →「現場とチェックリスト」→ 現場の「編集」→「点検箇所を追加」から、箇所名・基準写真・基準位置・チェック項目を登録します。登録すると、KY開始で巡回リストが開きます。

記録を修正・削除できますか？

改ざんを検知できる記録とするため、封印した記録は編集・削除できません。古い記録は、設定 →「古い記録を書き出して削除」で、ZIPに書き出してから古い順にまとめて整理できます。

記録が書き換えられていないか確かめるには？

設定 →「全記録を検証」で、写真・音声・内容と記録同士のつながりを確認できます。第三者による確認は、証跡一式（manifest.json ほか）に同梱の README.txt の手順で行えます。

機種変更のときは？

記録は端末の中に保存されています。設定 →「古い記録を書き出して削除」の手順で記録一式をZIPに書き出して保管してください。設定・現場・チェックリストは、設定 →「設定を書き出す」（Pro）で新しい端末に移せます。

Pro では何ができますか？

現場・点検箇所の無制限、本日の巡回まとめPDF、報告書の会社名・確認欄・文書番号、自社の危険の種類と対策、設定・現場のチームへの配布、高画質の写真です。KYの記録・封印・改ざん検知・記録ごとのPDFは無料版でもずっと使えます。

購入を復元するには？

設定 →「ゆびさしKY Pro」→「購入を復元」をタップしてください。

解約するには？

iPhone の「設定」→ あなたの名前 →「サブスクリプション」→「ゆびさしKY」から解約できます。アプリの設定 →「ゆびさしKY Pro」→「サブスクリプションを管理」からも開けます。
