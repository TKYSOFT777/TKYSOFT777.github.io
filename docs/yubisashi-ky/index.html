ゆびさしKYは、作業前のKY（危険予知）と指差呼称を、文字を打たずに30秒で記録するiPhoneアプリです。記録は写真・声・時刻ごと封印され、あとから書き換えると分かる「改ざんを検知できる証跡」になります。

HOW IT WORKS

現場での流れ

紙のKYシートに毎日同じ文言を書くだけ、をやめるための流れです。

1

現場を撮る

点検する場所を撮影。日時と位置が写真に残り、その場で点検した裏付けになります。基準写真と見比べて撮れます。

2

声で点検

項目を指差して「〇〇ヨシ！」。聞き取ると自動で次の項目へ。問題があれば「問題」と言うだけで報告に進みます。

3

封印して提出

写真・声・時刻をまとめて封印。報告書PDFや、1日の巡回まとめPDFを元請にそのまま送れます。

FEATURES

現場の手間を減らす機能

危険箇所の報告

問題があれば、撮影して丸を付け、状況を声で話し、対応（是正済み・作業中止・職長に報告）を選びます。是正後は「対策ヨシ！」の呼称まで記録。

現場・点検箇所ごとの項目

広い工場や倉庫でも、箇所ごとに基準写真とチェック項目を登録。巡回リストで、まだの箇所が近い順に並びます。

声の入力と記録

騒音を抑えて録音し、その場で文字起こし。「よーし」などの崩れた発音も読みで判定します。録音そのものも証跡に残ります。

報告書PDF

見やすいUDフォントの報告書。確認欄（ハンコ枠）・会社名・文書番号を自社の様式に合わせられます（Pro）。

細かく設定できる

聞き取る時間、合言葉、危険の種類、写真の必須・省略など、会社の運用に合わせて変えられます。設定はチームに配れます（Pro）。

端末の中で完結

記録は端末の中に保存。アカウント登録は不要です。古い記録はZIPに書き出してから整理できます。

EVIDENCE

「あとから書いたのでは？」に答えられる

紙の記録は、作業前に書いたことを証明できません。ゆびさしKYは記録を封印し、書き換えると検出できるようにします。

ハッシュで封印

写真・声・内容の指紋（SHA-256）を記録に封入。1バイトでも変えると一致しなくなります。

記録のつながり

各記録に前の記録の指紋を入れて鎖のようにつなぐので、途中の削除や差し替えも検出できます。

第三者の時刻証明

記録の指紋だけを第三者の時刻認証局（RFC 3161）に送り、その時刻に存在した証明を受けます。写真や声は送りません。
