1. 本アプリの性質

  • 本アプリは、作業前のKY（危険予知）活動・点検・指差呼称を記録するための補助ツールです。現場の安全を保証するものではなく、事業者・元方事業者・作業者が負う安全管理の義務や判断に代わるものではありません。
  • 音声の聞き取り・文字起こし・「ヨシ」等の判定は自動処理のため、誤ることがあります。正式な記録は録音そのものです。
  • 改ざん検知（ハッシュ・記録のつながり）と第三者の時刻証明は、記録が変更されていないことや、ある時刻に存在したことの確認を助ける技術的な手段です。特定の手続き・紛争・審査において、証拠として採用されることや法的な効力を保証するものではありません。標準の時刻証明（FreeTSA）は、総務大臣の認定を受けた時刻認証業務ではありません。
  • 位置情報は端末の測位によるもので、屋内などでは誤差が大きくなります。

2. ゆびさしKY Pro（自動更新サブスクリプション）

  • 月額プラン・年額プランがあります。価格はアプリ内および App Store に表示されます。
  • はじめて登録する場合に限り、最初の1か月間の無料体験があります。体験期間が終わる24時間前までに解約しなければ、有料の期間が自動で始まります。
  • 支払いは購入の確定時に Apple ID に請求されます。期間が終わる24時間前までに解約しない限り、同じ期間・価格で自動更新されます。
  • 解約・プランの変更は、iPhone の「設定」→ あなたの名前 →「サブスクリプション」、または本アプリの設定 →「ゆびさしKY Pro」から行えます。期間の途中で解約しても、残りの期間の返金は行われません（返金は Apple の規定によります）。
  • Pro が終了すると、無料版の範囲に戻ります。保存済みの記録は削除されず、すべて閲覧・PDF作成・書き出しができます。
