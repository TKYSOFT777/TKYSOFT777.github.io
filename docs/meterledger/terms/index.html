1. 本アプリの性質（読み取り値について）

本アプリは、写真からメーターの値や銘板の文字を読み取る支援を行うものです。読み取り結果は、撮影の条件やメーターの状態により実際と異なる場合があります。記録は利用者が写真と見比べて確認し、確定するものとします。本アプリの値・判定をもとにした判断・作業・報告の結果について、私たちは責任を負いません。安全に関わる判断は、必ず実物と所定の手順で確認してください。

2. 証拠写真・改ざん確認について

証拠写真への情報の焼き込みと、写真の指紋（SHA-256）による確認は、記録の確かさを補うための機能です。特定の法令・規格・契約上の要件を満たすことを保証するものではありません。

3. メーターヨミトル Pro（自動更新サブスクリプション）

  • 月額プラン・年額プランがあります。価格はアプリ内および App Store に表示されます。
  • 年額プランには、最初の1週間の無料体験があります（はじめて登録する場合のみ）。体験期間の終了の24時間前までに解約しなければ、有料の期間が自動で始まります。
  • 支払いは購入の確定時に Apple ID に請求されます。期間終了の24時間前までに解約しない限り、同じ期間・価格で自動更新されます。
  • 解約・プランの変更は、iPhone の「設定」→ あなたの名前 →「サブスクリプション」、または本アプリの設定画面から行えます。期間の途中で解約しても、残りの期間の返金は行われません（返金は Apple の規定によります）。
  • Pro を解約すると、無料版の範囲（メーターの新規登録は10個まで、PDF 報告書は透かし入り）に戻ります。保存済みの記録は削除されず、閲覧・修正・書き出しはそのまま行えます。
